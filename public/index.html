Firebase Authentication Setup Guide

Follow these 5 simple steps to connect your free Google Firebase project so users worldwide can sign up and log in:

Step 1

Open the Free Firebase Console

Visit https://console.firebase.google.com/ and sign in with your Google account.

Step 2

Create a New Project

Click "Add project", name it JoynessHobby, choose default settings, and click "Create project".

Step 3

Enable Email/Password Authentication

In the left menu, click "Build" → "Authentication" → click "Get started".

Under Sign-in method, enable Email/Password and click Save (and enable Google if desired).

Step 4

Register Web App & Copy Keys

Click the Settings Gear ⚙️ → Project settings → scroll down to "Your apps" → click the Web icon </>.

Enter nickname "Joyness Web", click Register app, and copy your firebaseConfig keys.

Step 5

Paste Keys into static/js/firebase-config.js

Open the file static/js/firebase-config.js in this project and paste your keys into firebaseConfig:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "joynesshobby.firebaseapp.com",
  projectId: "joynesshobby",
  storageBucket: "joynesshobby.appspot.com",
  messagingSenderId: "123456789...",
  appId: "1:123456789:web:..."
};

Enter Firebase Web API Key Key Required

Paste your Firebase Web API Key (starts with AIzaSy...) to instantly connect Firebase Auth and Cloud Firestore:

Step 1

Open Project Settings in Firebase Console

Go directly to your project settings: https://console.firebase.google.com/project/joyness-hoby/settings/general

Step 2

Copy your Web API Key

Under the General tab, look at Web API Key (starts with AIzaSy...), or scroll to "Your apps" → find Web App 1:542346124070:web:1e6a25629608900e66ffe7 and copy the apiKey.

Paste it in the box above or into static/js/firebase-config.js.

Step 3

Enable Email/Password & Google Sign-in

In the Firebase Console left menu, go to Build → Authentication → Sign-in method:

• Enable Email/Password and click Save.

• Enable Google (select your support email) and click Save.

Step 4

Create Cloud Firestore Database

In the left menu, go to Build → Firestore Database → click "Create database".

Choose your nearest location (e.g. asia-southeast1 or nam5) and start in production/test mode. Your database collections (users/{uid}/watchlist, users/{uid}/tcg_cards, users/{uid}/tcg_decks) will synchronize automatically!
